一句话先想清楚

这套记忆系统到底做了什么？

技术版（自己心里清楚）：对话里即时抽取「值得跨轮保留的事实」存为快记忆；会话结束后，离线把这些快记忆整合、去重、纠错，沉淀成结构化的长期记忆；对话时按相关性召回，并根据「有没有被用到 / 被提起」对每条记忆做强化或遗忘。

对评委的一句人话：我们的玩具会把重要的事记住、定期整理、学会遗忘，越用越懂孩子。

下面 6 个点是这套设计的骨架。每个点都按「做了什么 → 为什么是创新 → 怎么对评委讲」展开，扫一遍就能记住。

全景

一条记忆的完整旅程

四个环节串成闭环，记忆不是「存聊天记录」，而是被持续加工、更新。
设计点

① 双层记忆：快记忆 → 长期记忆

1把「记忆」从「对话」里单独拿出来管
做了什么
对话中即时抽取「值得跨轮保留的事实」存成快记忆（标题 + 摘要 + 正文）；随后沉淀为结构化长期记忆，按 self / person / project / topic / entity / event 六类组织，每条带标题、别名、概括和细节。
怎么更快
快记忆写入时不做「逐条匹配已有记忆、判断是否重复」这类耗时操作，直接追加落库；匹配、去重、合并这些重活，放到会话结束后的离线整合里慢慢做——所以在线对话不卡。
为什么算创新
把记忆从对话里剥离出来、单独存、单独检索，而不是跟着对话走——记忆量可控、能更新、能长期保留，也不受单次对话长度的限制。
可对评委讲

玩具不是「记住聊天记录」，而是像人一样，把重要的事提炼成长期记忆。

设计点

② 离线整合：「睡一觉」再整理

2会话结束后，后台跑一条整合流水线
做了什么
会话结束后，不在对话里做重活，而是离线跑一条流水线：冻结 → 会话内整理 → 跨会话归并 → 归入已有记忆 → 生成内容 → 容量控制 → 独立校验 → 价值结算 → 提交。每一步有检查点，失败可重试、重复提交只生效一次。
为什么算创新
「跨会话」的整合——比如今天说喜欢草莓、下周又说喜欢，能合并成同一条——在线即时回答是做不动的，放在后台离线做，既不拖慢对话，又能做更复杂的整理。
可对评委讲

孩子聊完、玩具「睡一觉」，把白天的事整理成长期记忆。

设计点

③ 会遗忘：记忆有「生老病死」

3不是记住所有，而是懂得哪些该留下
做了什么
每条记忆是独立的「价值单元」，带一个价值状态（当前价值、遗忘时间等），会随时间衰减；生命周期分三态：活跃 active → 观察 observing → 归档 archived，归档后不再参与检索。
为什么算创新
记忆如果只增不减，会越用越脏、越来越吵。可控的遗忘让记忆「抗噪」——只留下真正有用的，检索更准，回答更贴。
记忆的价值是「算」出来的，不是存进去就永久等权。
可对评委讲

真正的智能不是记住一切，而是知道该忘掉什么。

设计点

④ 越被提起，记得越牢

4记忆会「用进废退」
做了什么
系统记录「哪条记忆在对话里被实际召回了」；被召回的、或孩子反复提起的，价值会被强化；没人再提的，随衰减慢慢淡出。这是一个闭环，不是一次性写入。
为什么算创新
这相当于让玩具自己学到「什么对孩子重要」——不是靠预设规则，而是靠孩子的真实行为（反复说、反复问）自然加权。
可对评委讲

孩子反复念叨的事，它会记得更牢；没人再提的，自然淡去。

设计点

⑤ 说错能改，不会记混

5记忆能「纠正、更新」，而不是只增不减
做了什么
对矛盾信息有明确处理规则：明确纠错只保留正确结论；状态变化以当前为准、保留有过的变化；无法解释的冲突采信较新的，且不凭空猜测原因。
为什么算创新
如果记忆只追加、不更新，孩子一改口就会变成两个互相矛盾的答案。这里把「更新语义」做成了硬规则，记忆能跟着孩子一起变化。
可对评委讲

孩子说「我改叫小明了」，它不会再喊旧名字——记忆是活的，会跟着人变。

设计点

⑥ 检索可分级、可降级

6需要多少，召回多少
做了什么
检索分弱检索（先命中相关记忆块，再在块内找细节）和强检索（块与细节平级直接召回）；标题/别名精确命中优先，向量召回兜底。任一环节失败会降级，不阻断正常对话。
为什么算创新
保证「日常闲聊」和「认真追问」用不同力度取记忆，且在检索故障时玩偶也不会变哑巴——这是可靠性的工程细节。
可对评委讲

闲聊时它像人一样「泛想」，认真问时它「精准回忆」，而且怎么都不掉链子。

再往上一层 · 愿景

从「记忆」到「画像」

记忆积累到一定程度，就不只是孤立的「事实」，而是一堆持续的行为与偏好线索。把这些线索再聚合，可以进一步做：

性格倾向好奇型 / 敏感型 / 外向型……
兴趣演变喜欢过什么、正在转向什么
情绪轨迹开心 / 焦虑的变化趋势
成长时间线认知、语言、关注点的变化
⚠ 注意：这是记忆数据之上的延伸方向，属于「下一步」的规划，不是已交付功能。对评委讲的时候把它当「愿景」说，别让人以为是已经做好的东西——说成愿景反而可信。
可对评委讲

长期看，它不只是玩具，而是一份持续更新的「成长档案」，一扇让家长读懂孩子的窗。

六句话串成一段

① 它把重要的事从对话里提炼出来，不是存聊天记录。

② 会话结束后离线整理，像「睡一觉」把记忆沉淀好。

③ 记忆会遗忘，只留下真正有用的。

④ 越被提起记得越牢，自己学会什么对孩子重要。

⑤ 说错能改，记忆跟着孩子一起变。

⑥ 再往上，是从记忆长出的性格画像——这是愿景。
